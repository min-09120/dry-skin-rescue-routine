# 나의 악건성 구조 루틴

화장대 사진에서 제품 라벨을 읽어 아침·저녁 기초화장 순서를 추천하고, 악건성 피부의 상황별 관리 순서와 들뜨지 않는 메이크업 방법을 확인하는 정적 웹앱입니다.

## 사용 방법

1. `사진 분석`에서 제품 이름이 보이는 화장대 사진을 올리고 분석 버튼을 누릅니다.
2. 인식된 제품 종류와 추천된 아침·저녁 순서를 확인합니다.
3. 위쪽 메뉴나 상황별 버튼을 눌러 원하는 내용을 확인합니다.
4. 하루 체크 항목을 선택하면 이 브라우저에 선택 상태가 저장됩니다.
5. `체크 초기화` 버튼을 누르면 저장된 체크 상태가 지워집니다.

## 내 컴퓨터에서 보기

`index.html` 파일을 더블클릭하면 기본 웹 브라우저에서 열립니다.

> 이 웹앱의 내용은 일반적인 피부 관리 참고 정보이며, 진단이나 치료를 대신하지 않습니다.
