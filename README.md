# 나의 악건성 구조 루틴

가지고 있는 보습 제품을 활용해 아침·저녁·한겨울·피부 응급 상황별 관리 순서와 들뜨지 않는 메이크업 방법을 확인하는 정적 웹앱입니다.

## 사용 방법

1. 위쪽 메뉴나 상황별 버튼을 눌러 원하는 내용을 확인합니다.
2. 하루 체크 항목을 선택하면 이 브라우저에 선택 상태가 저장됩니다.
3. `체크 초기화` 버튼을 누르면 저장된 체크 상태가 지워집니다.

## 내 컴퓨터에서 보기

`index.html` 파일을 더블클릭하면 기본 웹 브라우저에서 열립니다.

> 이 웹앱의 내용은 일반적인 피부 관리 참고 정보이며, 진단이나 치료를 대신하지 않습니다.
